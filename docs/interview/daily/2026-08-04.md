## Product And Engineering Judgment

The strongest evidence in Echo is not feature count. It is the sequence of observable decisions:

1. Separate-app collection created too much entry friction, so capture moved into the browser workflow.
2. Weak lexical overlap created distracting recalls, so diagnostics came before model complexity.
3. Vector retrieval improved paraphrase recall but increased false surfaces, so it was not shipped.
4. Local-first storage remained a deliberate privacy boundary rather than a missing cloud architecture.

The documentation now separates current truth from historical evidence. This makes old failed hypotheses useful instead of embarrassing or misleading.

## Remaining Evidence Gaps

- The current retrieval dataset is constructed rather than a manually desensitized real dogfood set.
- Recall feedback does not yet distinguish `useful`, `not_relevant`, and `wrong_time`.
- Product screenshots and a rehearsed three-minute demo are still missing.
- The project demonstrates browser-local reliability, not production-scale backend traffic or SLA evidence.

## Next Step

Define the annotation and privacy standard for `dogfood-anonymized-v1` before changing the benchmark runner. Freeze current retrieval behavior, label approximately 50 desensitized Echoes and 30 queries before viewing algorithm results, and use the first run as evidence rather than a target to optimize against.
